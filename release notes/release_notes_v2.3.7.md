# ThinkReview - Version 2.3.7 Release Notes

**Release Date:** 12 August 2026

---

## 🎯 What's New

### Full sidebar layout now fills the screen 📐

The **Full Sidebar** layout now stretches from the top to the bottom of your browser window, giving you a true side-by-side view of your pull request and the review panel. Previously, the panel could sit below the top of the page and leave an awkward gap — that is fixed in this release.

### Clearer layout names and ordering in settings 🧭

Layout options in the settings menu are easier to scan:

- **Full Sidebar** (formerly "Docked Sidebar") is listed first, above **Sidebar Tab**, so the full-height layout is easier to find.
- Labels and the guided settings tour now say **Full Sidebar** instead of "Docked Sidebar," matching what you see on screen.

### Sharper logo in the review panel header ✨

The ThinkReview logo in the integrated review panel header now uses a higher-resolution image, so it looks crisp and clear on high-DPI displays.
