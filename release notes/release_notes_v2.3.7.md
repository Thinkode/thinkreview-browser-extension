# ThinkReview - Version 2.3.7 Release Notes

**Release Date:** 12 August 2026

---

## 🎯 What's New

### Two-step store feedback flow ⭐

After you've generated several reviews, ThinkReview now asks for your feedback with a compact inline prompt — **"What do you think of ThinkReview so far?"** — instead of jumping straight to a large popup. If you engage, a guided two-step flow helps you leave a quick store review or share detailed feedback. When a reward is available, you'll see a hint on the first step and a clear callout on the second.

### Store feedback may reappear after three months 🔄

If you previously left a store review or submitted feedback, ThinkReview will respect that choice for three months before politely asking again. Choosing **Maybe Later** or closing the popup with the **X** still gives you a seven-day break before the prompt returns.

### Full sidebar layout now fills the screen 📐

The **Full Sidebar** layout option now correctly stretches from top to bottom of your browser window, so the review panel uses the full viewport height when docked to the left or right edge.

### Clearer layout names in settings ⚙️

Layout options are easier to scan: **Full Sidebar** (the edge-to-edge docked panel) is now listed above **Sidebar Tab**, and the settings tour uses the same naming so everything stays consistent.

### Sharper logo in the review panel header 🖼️

The ThinkReview logo in the integrated review panel header now uses a higher-resolution image, so it looks crisper on high-DPI displays.

### Quick link to star ThinkReview on GitHub 🌟

A new **Star** link sits beside the version number in the review panel header, making it easy to open the ThinkReview GitHub repository and show your support.

### Panel settings tour waits until you're signed in 🧭

The first-time guided tour for panel settings now only appears when you're logged in. If you sign in after opening the panel, the tour can still start on your next visit — it won't be skipped just because you browsed while signed out.

### Store feedback stays tied to an open panel 💬

The store feedback prompt only appears while the integrated review panel is open, so it won't interrupt you when the panel is minimized or closed.
