# ThinkReview - Version 2.3.7 Release Notes

**Release Date:** 12 August 2026

---

## 🎯 What's New

### Two-step feedback flow for store reviews 💬

After you've generated several reviews, ThinkReview now invites you to share feedback in a friendlier two-step flow. A compact message appears inside the review panel with **Share feedback** and **Maybe Later** options. Choosing **Share feedback** opens a guided popup: first you can tell us what you think, then we help you leave a quick review on the Chrome Web Store or Firefox Add-ons. Closing the popup with **X** works the same as **Maybe Later**, so you're never stuck in an awkward prompt.

### Optional reward messaging when you share feedback 🎁

When a reward is available, step one of the feedback popup can show a short reward hint, and step two celebrates your feedback with a clear **Reward unlocked** callout. Reward text comes from ThinkReview's remote configuration, so messaging stays current without needing an extension update.

### We'll ask again after three months — not forever 🔁

If you previously shared feedback or left a store review, ThinkReview now waits about three months before inviting you again instead of hiding the prompt permanently. That gives you space after you respond while still making it easy to share updated thoughts later.

### Feedback prompts stay tied to an open review panel 📋

Store feedback invitations only appear while the integrated review panel is open. Minimize or close the panel and the prompt goes away with it, so feedback never lingers over your PR page when you're not actively reviewing.

### Guided panel tour for signed-in users only 🧭

The first-time settings tour in the review panel now starts only when you're signed in, so new visitors aren't walked through account-linked options before they've connected ThinkReview.

### Star ThinkReview on GitHub from the panel header ⭐

A new **Star** link sits under the version number in the review panel header, making it easy to support the project on GitHub without leaving your pull request. Your subscription label and version info are also aligned for a cleaner header layout.

### Full Sidebar now fills the entire page 📐

The **Full Sidebar** layout stretches from the top to the bottom of your browser window, giving you a true edge-to-edge review panel. Whether you dock it on the left or right, the panel stays fully visible without awkward gaps at the top or bottom.

### Clearer layout names and ordering 🧭

Layout options in the settings menu have been reorganized for clarity:

- **Full Sidebar** (formerly "Docked Sidebar") now appears above **Sidebar Tab**, making it easier to find the full-height panel option.
- The guided settings tour and layout picker use the updated **Full Sidebar** name so everything stays consistent.

### Sharper logo in the review panel ✨

The ThinkReview logo in the integrated review panel header now uses a higher-resolution image, so it looks crisp and clear on high-DPI and retina displays.
