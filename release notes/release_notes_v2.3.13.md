# ThinkReview - Version 2.3.13 Release Notes

**Release Date:** 11 October 2026

---

## 🎯 What's New

### Post an AI chat reply to the pull request 💬

AI answers in the review chat now include the same **Post** control you already use on severity and scoring findings. When Copilot finishes a reply — including generated PR descriptions or follow-up answers — click **Post** to publish that message as a **conversation comment** on the open pull request or merge request (GitHub, GitLab, or Azure DevOps).

Nothing is sent until you click. Post still uses your **Full Context** connection (GitHub App, GitLab OAuth/PAT, or Azure PAT). If Full Context is not set up, Post opens the setup hint instead of failing silently.

---

## 🐛 Bug Fixes

- Severity and scoring findings keep long file paths, explanations, and inline code inside the card instead of spilling past the panel edge.
- Copy and Post icons on severity findings stay pinned in the top corner of each card so they no longer squeeze the title or description.
