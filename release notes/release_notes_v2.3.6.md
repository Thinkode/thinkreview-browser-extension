# ThinkReview - Version 2.3.6 Release Notes

**Release Date:** 10 August 2026

---

## 🎯 What's New

### Friendly in-page messages instead of browser pop-ups 💬

ThinkReview no longer interrupts you with plain browser alert boxes. Messages now appear as styled toasts near the ThinkReview button on your PR page — for example, when you need to open a pull request before starting a review. The extension popup and sign-in flow use the same polished style for errors, confirmations, and success messages.

### Severity is now the default review format 📋

New reviews default to the **Severity** layout, which highlights critical, high, and low issues in your PR description. If you prefer the scorecard-style **Scoring** layout, you can still switch anytime from the review format picker in the panel header.

### Interactive tour for panel settings 🧭

The first time you expand the review panel, a guided tour walks you through the key controls — review format, text size, language, the settings gear menu, layout options, and auto-start. You can skip at any time, and the tour won't show again once you've completed it.

### ThinkReview button appears sooner on PR pages ⚡

The ThinkReview trigger now shows up faster when you land on a pull request page, so you can start a review without waiting for the full page to finish loading.

### Wider review panel for easier access to settings 📐

The integrated review panel is now wider by default, giving the header controls — including text size, review format, and the settings gear — more room so they stay visible without feeling cramped. If you had previously resized the panel narrower, it will automatically adjust to the new minimum width.
