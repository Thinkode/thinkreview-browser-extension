# ThinkReview - Version 2.3.3 Release Notes

**Release Date:** 1 August 2026

---

## 🎯 What's New

### Severity review layout 🚨

You can now view AI reviews in a **severity-focused layout** that highlights what matters most. Reviews show your PR description up front, then group findings into **Critical**, **High**, and **Low** sections so you can triage issues quickly. Tap any issue to ask a follow-up question in the chat.

### Choose your review format from the panel header 📊

A new visual picker in the review panel lets you switch between **Scoring** (the familiar scorecard with strengths and suggestions) and **Severity** (PR description with prioritized issues). Your choice is remembered for future reviews.

### Custom Rules and Add an Agent on every review ✨

**Custom Rules** and **Add an Agent** shortcuts are now available in the review footer on both scoring and severity layouts, making it easier to tune review behavior or spin up an agent without leaving the PR page.

### MCP setup from the IDE assist menu 🧩

The **Implement via** menu in the review panel now includes an **MCP** option that opens MCP setup on the ThinkReview portal in one click, alongside your existing IDE integrations.

### Popup provider selection stays put 🔑

If you choose **ThinkReview Cloud** in the extension popup, it will no longer switch back to your self-hosted gateway just because a gateway URL is saved. Your explicit provider choice now persists across popup sessions.

### Cleaner review panel polish ✨

The integrated review header has been simplified, severity sections have clearer styling and color cues, and PR descriptions render more reliably in the new layout.
