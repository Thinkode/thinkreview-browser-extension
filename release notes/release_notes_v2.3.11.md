# ThinkReview - Version 2.3.11 Release Notes

**Release Date:** 30 August 2026

---

## 🎯 What's New

### Smoother loading when you hit the daily review limit ⏳

When you reach your daily review limit, the upgrade prompt now shows ThinkReview’s branded loader right away while your plan and credit-pack options load. Instead of a blank or dark panel, you’ll see a clear “Loading upgrade options” message with helpful tips until everything is ready.

---

## 🐛 Bug Fixes

- The upgrade prompt no longer leaves an empty panel while plan details are being fetched.
- If you navigate away from the pull request while the upgrade prompt is loading, the extension no longer tries to update a panel that is no longer on the page.
