# ThinkReview - Version 2.3.7.1 Release Notes

**Release Date:** 12 August 2026

---

## 🎯 What's New

### Microsoft Edge Add-ons distribution support 🟦

ThinkReview is now packaged specifically for the Microsoft Edge Add-ons store. Official release builds include an Edge-ready zip you can install from Edge Add-ons, so Microsoft Edge users get the same AI code review experience as Chrome and Firefox — without workarounds or manual sideloading.

### Store-friendly naming on Edge Add-ons ✨

The Edge Add-ons listing uses a shorter, store-compliant extension title so ThinkReview appears clearly in search results and on your extensions page, while keeping the full product name on other browsers.
