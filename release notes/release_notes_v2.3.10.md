# ThinkReview - Version 2.3.10 Release Notes

**Release Date:** 29 August 2026

---

## 🎯 What's New

### Sidebar tab stays purple on Azure DevOps Server (TFS) 💜

On Azure DevOps Server and other TFS-hosted pull request pages, the ThinkReview sidebar tab now keeps its familiar purple styling and full vertical label. Host page styles were stripping the background and clipping the tab; this update restores the look you see on Azure DevOps cloud and other supported platforms.

---

## 🐛 Bug Fixes

- The sidebar tab no longer appears transparent or cut off on Azure DevOps Server (TFS) pages.
- Hover styling on the sidebar tab works reliably on TFS, so the tab darkens when you point at it.
